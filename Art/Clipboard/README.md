# Clipboard artwork

`clipboard-concept.png` provides the warm paper, metal clip and transparent background for the HyperManage clipboard. Labels, keycaps and movement diagrams are rendered separately by the widget so they stay readable as settings change.

`Tools/Import-Clipboard.py` imports the texture as `/HyperManage/UI/Jusedawg/T_Clipboard` with UI compression and no mipmaps.

Kalam Regular supplies the handwritten lettering. Its [SIL Open Font License](https://github.com/google/fonts/tree/main/ofl/kalam) is included as `Kalam-OFL.txt`. The font and notice are packaged with the mod.
